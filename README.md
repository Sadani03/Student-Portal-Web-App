🎓 Student Portal Web Application

This is a PHP-based student portal system that allows students to register, login, manage profiles, view courses, and contact administrators.

Features

- User Registration & Login
- Student Profile Management
- Course Information Pages
- Contact Form
- Session Handling & Authentication

Technologies Used

- PHP
- MySQL (via config.php)
- HTML5 / CSS3
- JavaScript
- Bootstrap

Project Structure

student-portal/
│── assets/
│── includes/
│── php/
│── home.php
│── login.php
│── register.php

Setup Instructions

1. Install XAMPP/WAMP
2. Place project inside `htdocs`
3. Import database
4. Edit `/includes/config.php`
5. Run via `localhost/student-portal`
